# Adaptive Noise Cancellation using LMS Algorithm (MATLAB)

This project implements an adaptive noise cancellation system
using the Least Mean Square (LMS) algorithm in MATLAB.

A clean sine signal is generated and corrupted with Gaussian noise.
The LMS adaptive filter estimates and removes the noise, producing
a cleaned output with improved Signal-to-Noise Ratio (SNR).

## Features
- LMS adaptive filter
- Sine wave test signal
- Noise cancellation
- SNR analysis
- Time-domain visualization

## Tools
- MATLAB

## Results
SNR After Filtering is greater than SNR Before Filtering,
demonstrating successful noise reduction.
